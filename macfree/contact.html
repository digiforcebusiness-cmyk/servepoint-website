Reporting a problem

To help us diagnose it fast, please include:

  • Your Unity version and operating system (Windows / Linux / macOS)
  • Which engine you're using — GitHub Actions or Unity Build Automation
  • The exact message MacFree shows (it translates most errors into a plain-English hint), or the failing step in your build log
  • A screenshot, if the issue is visual

Common questions

Do I need a Mac? No. Every Mac-only step runs in the cloud; you drive it from the Unity Editor on Windows or Linux.

What are the requirements? Unity 6 with the iOS Build Support module, a paid Apple Developer Program account, and a Unity account (Personal works). For the GitHub Actions engine you also need a free GitHub account.

Where's the documentation? A full step-by-step PDF manual is included inside the asset, under Assets/MacFree/Documentation.
